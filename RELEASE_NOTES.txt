Version: 1.0.0

---------------------------------------------------------------
OFFICIAL BEHAVIOR
---------------------------------------------------------------
ENGAGE  = Keep only the Windows primary monitor active
          (via the CCD API: QueryDisplayConfig / SetDisplayConfig).
          GPU-, driver-, and port-independent.
RESTORE = DisplaySwitch.exe /extend

Note: earlier builds used DisplaySwitch.exe /internal for ENGAGE.
That kept whichever display Windows enumerated first, which depended
on the GPU and cabling. ENGAGE now targets the primary monitor by
identity (desktop position 0,0) so the correct monitor survives a
GPU change.

---------------------------------------------------------------
DISTRIBUTION
---------------------------------------------------------------
This is a portable single-file executable.
No installer required. No admin rights required.
No network access. No telemetry. No background service.

WARNING: Only download NSE.exe from the official release
location. Verify the SHA-256 hash before running any copy
obtained from a third party.
